# Cloud-Cost-Optimization

Project Description

Cloud Cost Optimization System is a Flask and MySQL based web application designed to help users select the most suitable cloud service provider according to their project requirements and budget.

Many users and organizations face difficulty in choosing the right cloud platform because different providers offer different pricing models and services. This system simplifies the decision-making process by analyzing user inputs such as project type, number of users, storage requirements, RAM, CPU cores, budget, and free-tier preference.

Based on the provided requirements, the system recommends the most appropriate cloud provider (AWS, Google Cloud, or Koyeb) along with an estimated monthly cost. The application also generates reports and budget analysis to help users understand potential savings and make cost-effective cloud deployment decisions.

The system includes user registration, email notifications, login tracking, dashboard analytics, cloud service recommendations, and budget analysis features.


Problem Statement

Choosing the right cloud provider can be confusing due to varying pricing structures, service offerings, and resource requirements. Users often spend significant time comparing cloud platforms manually.
This project solves that problem by providing automated cloud provider recommendations based on project needs and budget constraints.

Project Workflow
User registers in the system.
Registration confirmation email is sent.
User logs in to the application.
Login notification email is sent with date and timestamp.
User enters project requirements.
System analyzes budget and resource requirements.
Best cloud provider is recommended.
Estimated cost is displayed.
Budget analysis and reports are generated.
